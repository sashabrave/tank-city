# Локальная библиотека ассетов

Запуск: двойной щелчок по `Открыть библиотеку ассетов.command` в корне проекта. Или `python3 tools/asset_library/server.py`. Откроется http://127.0.0.1:8765. Оставьте окно запуска открытым; Ctrl+C останавливает сервер. Другой порт: `--port 8766`.

Библиотека читает реальные файлы проекта, не создаёт их копии. Автопроверка каждые 15 секунд, когда вкладка видима; «Обновить данные» проверяет немедленно. Новые файлы известных форматов появляются автоматически. Категории соответствуют папкам; новый способ группировки можно добавить позже.

Четыре вкладки: графика, 3D, звук, остальные ресурсы (материалы, шейдеры, данные, шрифты, документы, видео). Код и сцены анализируются для ссылок, но не показываются как ассеты. Временные файлы, экспорты, ZIP-бэкапы, служебные файлы Godot и сама библиотека исключены. Демо, скриншоты и исходники включены и отделяются фильтром области.

Сортировка применяется внутри категорий; категории идут в порядке первого ресурса в общей сортировке. Важность — эвристика: прямые ссылки из игры → динамический загрузчик → игровой ресурс без найденных ссылок → демо → справочные материалы. «Число ссылок» означает количество строк со статическими ссылками, включая каталоги и тесты, а не частоту событий во время игры. Для загрузок через сборку пути показываются возможные места использования; этот анализ не доказывает использование или неиспользование каждого файла.

Картинки, аудио, видео, PDF и текст доступны в просмотре. GLB можно вращать и масштабировать, в том числе на весь экран; Blender и другие исходные 3D-форматы открывайте из Finder. Просмотр GLB использует локально сохранённый @google/model-viewer 4.1.0 (Apache-2.0); интернет для обычных GLB со встроенными ресурсами не нужен. Сжатые модели, требующие дополнительных декодеров, могут потребовать интернет; внешние ресурсы GLTF не обслуживаются.

«Открыть путь» выделяет файл в Finder. Его можно перезаписать вручную, оставив тот же путь и расширение. Или «Заменить файл»: выбрать новый файл того же расширения, подтвердить замену. Имя выбранного файла может отличаться — в проекте сохранится старое. Ограничение 256 МБ. Старый файл сохраняется в `.asset-library-backups/<дата>/<id>/<путь>`; восстановление — ручное копирование обратно. Если файл изменился после открытия карточки, замена отклоняется до обновления данных. Проверяется расширение, а не совместимость внутренней структуры модели или материала.

Godot увидит изменение исходного файла и переимпортирует его. `.import` и `.uid` не меняются библиотекой. Уже запущенной игре может потребоваться перезапуск. Изменение структуры узлов модели, анимаций или ключей JSON может нарушить потребителей ресурса — сохранение имени не гарантирует совместимость содержимого.

Сервер слушает только 127.0.0.1, проверяет Host и токен записи. Доступ ограничен индексируемыми ассетами; произвольные пути и симлинки не обслуживаются. Резервные копии исключены из Git и импорта Godot.

## Актуальность 3D

По умолчанию вкладка 3D показывает модели текущего маршрута `Visuals.model`: семейство пехоты и техники извлекается из `scripts/visuals.gd`, окружение учитывает приоритет и наличие файлов. Остальные версии доступны в фильтре «Все версии и исходники» / «Старые / резервные». Это выбор загрузчика, а не телеметрия: отдельная модель может быть запасной и не появляться в конкретном забеге. Если структура загрузчика перестанет распознаваться, модели получают статус «Не подтверждено». При изменении маршрутизации обновите правила `model_routes.py`.
