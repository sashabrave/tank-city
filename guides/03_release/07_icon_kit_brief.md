# Иконки: правила, словарь метафор и листы (GPT Image 2.5 через Higgsfield)

2 октября 2026. Игровая иконка — один чёткий нарисованный предмет: без плашки, рамки, слоёв и анимации. id иконки сопоставлен с символом в `data/icon_kit.json`, PNG лежат в `assets/ui/icon_kit/symbols` (384×384). Рисует Claude: `higgsfield generate create gpt_image_2_5`, листами 4K на прозрачном фоне; листы хранятся в `art_requests/icon_kit_v1/sheets` в 3/4 размера. Нарезку делает `tools/art/build_icon_kit.py`: он не перезаписывает сплав и жетон, выбранные автором.

## 1. Правила игровых иконок

Источник — разборы по геймдизайну ([Game Developer: Icon design rules](https://www.gamedeveloper.com/design/icon-design-rules-you-should-know)), опыт иконок способностей в мобильных играх и приёмки этого проекта.

0. **Штаб — машина, база — ангар.** Штаб в игре — передвижная командная машина; рисовать её (или модуль на ней), а не бункер, палатку или здание. База — хаб-ангар.
1. **Иконка — один нарисованный предмет без плашки и рамки.** Смысл читается по силуэту; цвет помогает, но иконка должна читаться и в оттенках серого.
2. **Один смысл — один символ во всей игре.** «Сердце» — здоровье и в карточке забега, и в прокачке, и в бонусе. Разные карточки забега не делят символ (это проверяет тест).
3. **Простые бытовые метафоры:** пламя — горение, молния — ЭМИ, спираль со звёздами — оглушение, факел — горит дольше, градусник — жарче. Не придумывать новое, если есть привычный знак.
4. **Один крупный предмет в центре.** Мелкий обвес, тонкие линии, значки поверх и надписи запрещены.
5. **Проверка на размере 32 px.** Символ узнаётся на 32 px и в оттенках серого. Соседние иконки различаются силуэтом, а не цветом.
6. **Цвета не спорят друг с другом.** Редкость карточки — её рамка и тонированный фон (серый, синий, фиолетовый, золото), не иконка.
7. **Направление — вправо.** Стволы, носы машин, снаряды, стрелки, взгляд.
8. **Свет сверху слева, мягкий объёмный «игрушечный» 3D, без обводок.** Как текущий набор GPT.

**Способности** : airstrike — самолёт сбрасывает бомбы; ally_drone — квадрокоптер; barrier — противотанковый ёж; cloak — капюшон с исчезающим краем; comrade — каска кота и плюс; dynamite — шашка с фитилём; gas — облачко с листом мяты; grenade — граната; laser — турель с лучом; mine — мина; shield — штурмовой щит с лапой.

**Бонусы** : freeze — снежинка; heart — heart_cage; pressure — bullet_vs_rocket; repair — командная машина штаба с ключом; star — звезда; turret — турель; vehicle — силуэт машинки; vehicle_repair — ключ на колесе; wall — кирпичи.

**Штаб — это наша передвижная командная машина** (бронированный грузовик 4×4 с тарелкой связи, её защищаем в бою), а не здание. База — хаб-ангар. Все картинки штаба показывают эту машину или её модули: hq_medbay — медицинский модуль с красным крестом на креплениях; hq_plating — бронепанели; hq_regen — рука-манипулятор с ключом; hq_supply — ящик снабжения; hq_interceptor — ракета-перехватчик; hq_tesla — катушка с молниями; hq_patch — кольцевой импульс с крестом; hq_field — купол; hq_emp — тарелка с волнами.

**Гараж**: `armor` — бронеплита, `gun` — ствол со вспышкой, `loader` — патронная лента; у трёх машин одинаковые символы веток, машину показывает группа плиток на Стоянке.

**Верстаки** : character — принтер бойца; command — экран с картой; garage — навес с машиной; headquarters — бункер с антенной; mechanic — ящик с ключом; merchant — палатка с навесом; range — мишень на мешках; recycling — пресс с шестерёнкой; roadmap — доска с флажками; wardrobe — шкафчик с формой; weapons — стойка с винтовками; yard — площадка с конусами.

**Статусы бойца** пока на прежних иконках: их id совпадают с бонусами, для символов нужен отдельный ключ.

**Ресурсы**: alloy — золотые слитки; token — серебряная монета с лапой; blueprint — свёрнутый синий чертёж; documents — папка с печатью; recipe — карточка-рецепт. Символ trophy нарисован, но пока не подключён.

Системные кнопки (закрыть, пауза, стрелки, меню, поиск, музыка) остаются линейными SVG: это управление, а не содержимое.

## 3. Устройство

- `UiKit.icon_texture(id)`: если id есть в `data/icon_kit.json` и PNG нарисован — возвращается символ (`IconKit.symbol`), иначе прежний поиск. Экраны просто назначают texture; ничего не анимируется.
- Карточки забега (`choice_card.minimal`): символ 124 px без рамки; редкость — рамка карточки и фон `RarityGlow` (`shaders/ui/rarity_card.gdshader`): мягкий градиент в цвет редкости, пятно света за иконкой и редкий случайный блик раз в 7–11 с. Блик выключается настройкой «Анимации интерфейса». Шевроны «уже взято» остаются под иконкой.
- Новый символ: строка в листе (`art_requests/icon_kit_v1/sheets`), имя в `build_icon_kit.py`, id → символ в `data/icon_kit.json`.
- Проверка: `tests/icon_kit_visual.tscn` в окне — карточки без рамки с тонированным фоном, у каждого id свой нарисованный символ, карточки забега не делят символ; кадры `/tmp/r13-icon-kit-*.png`.

## 4. Каталог и инспектор иконок

- `guides/02_development/09_icon_catalog.md` — список всех иконок по группам: файл, id, название, где используется. Его и `data/icon_catalog.json` собирает `tools/art/build_icon_catalog.py`; после новых картинок запускать заново.
- В игре: правый клик по любой картинке интерфейса открывает её карточку (`scripts/tools/icon_inspector.gd`, автозагрузка IconInspector): превью, название, группа, id, где используется, файл. Поле «Что здесь должно быть нарисовано?» и кнопка «На доску задач» создают задачу «Арт: …» с комментарием, данными картинки и скриншотом. «Копировать id» кладёт id в буфер. Игра стоит на паузе, Esc или клик мимо окна закрывают его. Проверка: `tests/icon_inspector_visual.tscn` (доска задач — во временном каталоге).
- Векторные значки (`interface_straight`, `reward_categories`, `current`) импортируются с `svg/scale=3`: окно 1440×810 на Retina растягивается вдвое, и 24-пиксельный растр был мыльным. Размер на экране задаётся явно (`icon_max_width`, `UiKit.icon`), поэтому значки не выросли; лупа поиска в планшете стала отдельной картинкой 20 px.

### Заглушки заменены (2 октября)
- Голые id без группы («fire», «luck», «hq_tesla») ищутся по группам набора (`IconKit.GROUP_ORDER`), смысловые слова и типы патронов — через `aliases` в `data/icon_kit.json`; легендарные правила по голому id получают свои золотые картинки.
- Категории наград (угол карточек сундуков, чертежей и торговца): нарисованные символы `category/…` вместо линейных силуэтов с подкраской.
- Аватары отправителей в ленте заданий: эмблемы `sender/…` — фуражка майора (Штаб усов), колба (Институт), гарнитура (Оперштаб).
- Линейными остаются только системные кнопки и вкладки (управление, а не содержимое).

## 5. История решений

- 2 октября: был собран конструктор из слоёв (основа группы, кант, символ, значок-модификатор) с параллаксом и отскоком. Автор поиграл и отказался: «рамка на рамке», анимация и сложная конструкция. Оставлены только символы; дублирующие варианты (пламя, спираль, молния со значками) заменены своими предметами.
- Решения автора после игры: способности — только символ; сплав — золотые слитки, жетон — светлая серебряная монета с лапой, без цветной подкраски (на поле, в счётчике, в полёте и при высыпании).
- Системные кнопки (закрыть, пауза, стрелки, меню, поиск, музыка) остаются линейными SVG: это управление, а не содержимое.
