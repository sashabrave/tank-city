# Клоду: настройка «Иллюстрации — GPT / Nano Banana»

30 сентября 2026. Пользователь заказал второй комплект именно через **GPT Image 2.5 в Higgsfield**, на прежних референсах до Nano Banana и правках приёмки. Nano Banana не использовалась как визуальный референс. Арт-агент подготовил оба набора рядом; код настройки оставлен Клоду по просьбе пользователя.

## Готовые папки

| Значение настройки | Надпись | Корень |
|---|---|---|
| `gpt_image_2_5` | GPT | `res://assets/illustrations/gpt_image_2_5/` |
| `nano_banana` | Nano Banana | `res://assets/illustrations/nano_banana/` |

В каждом корне одинаковые 86 относительных путей: 82 уникальные иконки, портреты, миниатюры, атлас врагов и атлас мастерских. `assets/illustrations/manifest.json` содержит точные соответствия старого пути обоим вариантам, размеры, сетки и хеши. Не переименовывать игровые id и не менять порядок ячеек.

Пример: `res://assets/icons/upgrades/crit_damage.png` → `res://assets/illustrations/<вариант>/icons/upgrades/crit_damage.png`. Атласы аналогично: `portraits/v16/portraits.png`, `portraits/v16/miniatures.png`, `ui/enemies/enemy_atlas_v1.png`, `ui/workshops/atlas.png`.

Принятые предметы/оружие/эффекты, сердца, гайд, логотип, служебные SVG, 3D-модели и шейдеры остаются общими. Настройка меняет перечисленный комплект иллюстраций, а не детализацию или производительность 3D.

## Что реализовать

1. В `scripts/settings.gd` добавить `illustration_set`, допустимые значения из таблицы. Рекомендуемый новый вариант по умолчанию — `gpt_image_2_5`, учитывая последнюю просьбу пользователя. При неизвестном значении использовать его же. Настройка глобальная, сохраняется через существующие Settings.change/save; не часть профиля или мира. Сброс настроек восстанавливает default.
2. Во вкладку графики добавить выбор «Иллюстрации» с вариантами «GPT» и «Nano Banana». Использовать существующий `choice` и `Texts`; английское название «Illustrations» добавить в `data/locales/en.tsv`. Вынести/сдвинуть последующие элементы и обеспечить прокрутку: сейчас после строки темы на y=270 идут переключатель шейдеров на y=322 и пояснение на y=355. Не накладывать новую строку поверх них.
3. Сделать общий resolver старого asset-пути. Он проверяет соответствие manifest/известным префиксам и наличие варианта, возвращает вариант либо исходный путь как совместимый fallback. Не подменять один выбранный набор другим молча; отсутствующий файл сигнализировать в dev-проверке. Общие картинки проходят без изменений.
4. `UiKit.icon_texture` **уже поддерживает** `upgrades/…`, `stats/…`, `abilities/…`, `headquarters/…`, `garage/…` — предыдущую интеграцию 0.4.0 не переделывать. В этой ранней ветке вместо жёсткого `res://assets/icons/…` использовать resolver. Семантические `icon` и отдельные `art_key` сохранить; категории, пояснение напора и игровые значения не менять.
5. Подключить resolver в `scripts/ui/class_gallery.gd::texture` для обоих атласов; в `scripts/ui/build_catalog.gd` для мастерских; в `scripts/ui/enemy_type_icon.gd` для врагов. Последний сейчас держит `const ATLAS=preload(...)`: такой preload навсегда фиксирует старую картинку, его нужно заменить выбором текущего набора при создании/обновлении. Сетки прежние: портреты/миниатюры/мастерские 3×2 (1536×1024), враги 4×4 (1254×1254, шаг 313.5).
6. Смена применяется сразу, без перезапуска/пересоздания мира. На Settings.changed обновлять уже созданные TextureRect, кнопки и AtlasTexture на видимых экранах: классы/портреты диалогов, карточки, станции, планшет, HUD навыков, навыки хаба и волны. Если есть кэш текстур/AtlasTexture, включать набор в ключ или очищать при смене. Одной замены пути в функции недостаточно: старые узлы сохраняют старую Texture2D.
7. Не переписывать PNG при переключении. Обе папки постоянно доступны; настройка выбирает ресурс. Не загружать все 172 файла заранее. Обеспечить включение динамически адресуемых PNG в экспорт: проверить существующий export filter, при необходимости явный ресурсный каталог/ссылки.

## Приёмка настройки

- В окне переключить GPT → Nano Banana → GPT в обеих UI-темах; картинки и открытые атласы обновляются сразу, без смешивания наборов.
- Проверить 82 соответствия: файлы существуют в обеих папках, пары имеют одинаковые размеры, внутри каждого набора нет повторяющихся хешей иконок.
- Проверить три разных field_repair (upgrades/stats/abilities), девять веток гаража, пулемёт/щит с гранатомётом в портретах, все 16 врагов. У спрайтов нет фона, сетка не захватывает соседнюю ячейку.
- Выбор сохраняется после обычного перезапуска; в автоматических проверках отключить Game.save_enabled и Settings.persistence_enabled. Проверку записи настройки выполнять только через отдельный временный путь. Не трогать реальные профили.
- Категории карточек, локализация, цены, кулдауны, баланс и механики остаются прежними. Проверить экспортированную сборку для динамических путей.

## Происхождение

GPT-исходники, промпты и ответы с фактическим model=`gpt_image_2_5`: `assets/source/cozy_ui_2026/gpt_image_2_5/generation.json`. Использованы pre-Nano-Banana cat-atlas-reference.jpg, support-sheet.png, workshops-reference.jpg и игровые dog-game-reference.jpg / mortar-game-reference.jpg. Коррекции портретов использовали только уже созданные GPT-изображения. Базовые Nano Banana файлы скопированы отдельно без перерисовки и без использования как референсов GPT.

Настройка ещё не реализована арт-агентом; текущий выбор игры эта работа не меняет.
