# Хендбук · 5. Эксплуатация, тесты и релизы

## Проверки

- **Headless-тесты:** `tests/<имя>.tscn` печатают `PASS/FAIL` и итог `N failures`. Запуск с таймаутом и временным HOME (см. главу 1).
- **Оконные проверки:** временный `tests/_*_probe.gd` + `.tscn`, сохраняет скриншот в `$SHOTS`; после проверки удалить.
- **Хаос и крайности:** `chaos_monkey` (`-- <сид> <шагов>`, ищем `SCRIPT ERROR` в логе), `extreme_builds` (15 билдов, пределы чисел).
- **Сравнение с базой:** если тест упал, проверить на предыдущем теге во временном worktree (`git worktree add --detach <scratch>/base <тег>` + копия `.godot`). Падает и там — долг, не регрессия.

## Сборка и версия

1. Слить рабочую ветку в `main` fast-forward-ом из main-папки. Чужие незакоммиченные файлы не трогать; одинаковые неотслеживаемые `.uid` копировать в ветку, коммитить там и удалять из main перед слиянием.
2. `tools/build/stamp_build.sh` → коммит «Номер сборки».
3. `Godot --headless --path . --import`, затем `--export-release "macOS" build/macos/WarCats-<версия>-b<N>.zip`; распаковать в `.app`; короткий запуск с временным HOME и `--verbose` без ошибок.
4. Импорт может создать новые `.uid` в main-папке — провести их через ветку тем же способом.

**Версия** в трёх местах: `BUILD_VERSION.txt` (`alpha-X.Y.Z`), `project.godot` (`config/version`), `export_presets.cfg` (`short_version`, `version` +1). Changelog: новые записи с `"version":"X.Y.Z"`; выпущенные теги не переписывать (сверять с `git show vX.Y.Z-alpha:data/changelog.json`).

**Тег:** `git tag -a vX.Y.Z-alpha -m "Альфа X.Y.Z"` на `main`, пуш `main`, рабочих веток и тега.

## Стадии

Альфа (механики меняются) → бета (контент мира 1 полный, только баланс, баги, скорость, плейтесты, демо) → релиз-кандидат (только критичные исправления) → 1.0. Подпись, нотаризация, публикация — отдельные действия с явного согласия пользователя.

## Ручки баланса

| Что | Где |
|---|---|
| Темп прохождения | `economy.tres`: `kill_alloy_scale`, `clear_reward`, `death_loss` |
| Сила техники | `GarageCatalog.PLAYER_ARMOR`, enemy `.tres` (damage, fire_interval, player_speed) |
| Пределы и переток | `CombatMods.CAPS`, `OVERFLOW`, `combat.minimum_fire_interval` |
| Редкость карточек | `RunUpgrades.TIER_BANDS`, гарантия `dry_offers>=2` |
| Боссы | `BossSystem.spawn_generators` (пороги, HP генератора, охрана) |
| Размеры полей | `Campaign.WORLDS[].sizes` (только нечётные) |
| Графика | `Settings.render_scale`/`AUTO_3D_PIXELS`, бюджет ламп, `world_lighting.STYLES` |

## Метрики, за которыми следить

- Размер сборки (0.3.0: 205 МБ zip), холодный старт, FPS в полном экране (3420×2146: хаб 82, бой 103, карта 96 на M4 с авто-масштабом).
- Время до генерала и его победы на живом плейтесте.
- Хаос-тест без ошибок на новых сидах после каждой крупной правки.
