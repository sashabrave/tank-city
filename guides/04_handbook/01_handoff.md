# Хендбук · 1. Передача дел агенту

Правила, быстрый старт и карта кода. Текущее состояние, открытые задачи и решения автора — в «Начать здесь → Передача дел агенту». Остальные главы хендбука: 2 — геймдизайн, 3 — архитектура, 4 — контент и ассеты, 5 — эксплуатация и релизы.

## Проект в двух абзацах

**War Cats** (раньше Tank City; «Рубеж — 13» — название заставы в сюжете) — изометрический тактический рогалайт на Godot 4.7. Боец в одиночку держит мобильный штаб на поле из клеток, отбивает волны пехоты, техники и дронов, захватывает вражеские машины и собирает билд из карточек. Между вылазками хаб-база: Казарма, Арсенал, Штаб, Стоянка, площадка с полигоном. Мир 1 «Пограничье» (7 этапов, генерал в конце) и бесконечный режим; миры 2–3 закрыты.

Текущая версия — альфа 0.8.0 «Демо» (тег `v0.8.0-alpha`). Платформы: macOS (основная), iOS-пресет есть. Главная ветка — `main`; работа идёт в ветках `feature/*` и `fix/*` от `main`. Пользователь говорит по-русски, ценит автономность, короткие отчёты и проверку в окне.

## Правила, которые нельзя нарушать

1. **Сохранения игрока святы.** В тестах `Game.save_enabled=false` и `Settings.persistence_enabled=false`. Замеры собранной игры запускать с временным HOME (`HOME=<scratch>/home`), чтобы не тронуть реальный профиль.
2. **Боевая случайность только из `run.combat_rng`.** Визуал, звук и декор используют свои генераторы (`RandomNumberGenerator` с сидом от `Game.visual_run_seed`). Никаких `randf()` в визуале: глобальный генератор влияет на сид забега.
3. **Тексты интерфейса — только через `Texts.set_text(control, source)`.** Новые строки добавлять в `data/locales/en.tsv`. Капс только для аббревиатур. Строки с `%s` и пробелами переводятся ненадёжно — подпись и значение делать отдельными фрагментами.
4. **Не создавать профиль автоматически при пустых слотах.** Создание мира — явный выбор игрока.
5. **Изменил правило — обнови гайд.** Игра читает `guides/**/*.md` в планшете (Тех. информация → Обновить).
6. **Каждое заметное изменение — пункт в `data/changelog.json`** (ru и en) в записи текущей версии.
7. **Визуальное проверять в окне** (скриншот через временный `tests/_*_probe`), не только headless.
8. **Git:** в `main` напрямую не коммитим, только слиянием (fast-forward из рабочей ветки). Пушить только по просьбе. После слияний проверять `grep -rn "^<<<<<<<" scripts data guides`.
9. **Общий checkout.** В main-папке и соседних worktree могут работать другие сессии (например, музыка). Не трогать их незакоммиченные файлы; при слиянии файлов музыки (`scripts/music_controller.gd`, `assets/audio/music/*.json`) брать версию из `main`.
10. **Не выдавать альфу за релиз.** Подпись, публикация и отправка в магазины — отдельные шаги с явного согласия.

## Как работать (быстрый старт)

```
# тест в headless (с временным HOME и таймаутом)
HOME=<scratch>/home perl -e 'alarm 150; exec @ARGV' /Applications/Godot.app/Contents/MacOS/Godot --headless --path . tests/<имя>.tscn

# визуальная проверка: временный tests/_x_probe.gd/.tscn сохраняет скриншот в $SHOTS, потом удаляется
SHOTS=<scratch> HOME=<scratch>/home Godot --path . tests/_x_probe.tscn

# сборка macOS (из main-папки, с реальным HOME ради шаблонов экспорта)
tools/build/stamp_build.sh            # номер сборки = число коммитов
Godot --headless --path . --import
Godot --headless --path . --export-release "macOS" build/macos/WarCats-<версия>-b<N>.zip
```

Сборку распаковать в `build/macos/War Cats <версия> b<N>.app` и коротко запустить с временным HOME: без ошибок в `--verbose` логе.

## Где что лежит

| Путь | Что там |
|---|---|
| `scripts/game.gd` | Автозагрузка `Game`: профиль, валюты, прокачка, постройки, классы, сохранение |
| `scripts/main.gd` | Поток экранов: хаб ↔ карта ↔ бой ↔ сервис, продолжение, песочница |
| `scripts/arena.gd` + `scripts/systems/*` | Координатор боя и системы (бой, враги, награды, поток, техника, босс, местность…) |
| `scripts/state/run_state.gd`, `room_state.gd` | Состояние забега и комнаты |
| `scripts/upgrades`, `scripts/stats`, `scripts/classes` | Карточки, характеристики, классы (реестры) |
| `assets/balance/**/*.tres` | Все игровые числа: враги, оружие, способности, карточки, характеристики, экономика, бой |
| `scripts/ui/*`, `scripts/ui_kit.gd` | Интерфейс: планшет, станции, карточки, HUD-элементы, стекло, табы |
| `scripts/hub.gd`, `route_map.gd` | Хаб-база (площадка тренировочного забега на арене, guides/02_development/07_one_world.md) и карта маршрута |
| `scripts/battle_stage.gd`, `battle_presentation.gd` | Постановка боя и камера |
| `data/` | Changelog, энциклопедия, локаль |
| `tests/` | ~260 сцен проверок (headless и оконные), наборы в `tests/suites`, запуск `tools/run_tests.sh` |
| `tools/` | Генераторы моделей (Blender), аудио, локализации, библиотека ассетов, сборка |
| `guides/` | Эта документация |

## Проверки, которые должны оставаться зелёными

`tools/run_tests.sh quick` после каждой заметной правки, `tools/run_tests.sh full` перед сборкой. Ключевые: `meta_integrity_revision` (эпик-тест связности меты), `chaos_monkey` (сиды по 1200 действий), `extreme_builds`, `stability_v09`, `boss_campaign_revision`, `stations_revision`, `localization_revision`. Текущие падения и долги — в «Передаче дел агенту» и `02_development/04_testing.md`.
