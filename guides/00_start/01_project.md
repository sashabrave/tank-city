# Проект и точка входа

Tank City / «Рубеж — 13». Рабочая альфа 0.1.0, 28 сентября 2026.

Это одиночный изометрический экшен-роглайт: боец защищает штаб, захватывает технику, собирает усиления и чертежи, выбирает маршрут и возвращается развивать базу. Визуальный ориентир — уютные военные миниатюры с выразительным светом и читаемыми материалами.

## Как читать эту папку

- «Геймдизайн» описывает текущие правила игры, а не обещанные функции.
- «Разработка» объясняет устройство проекта и ограничения для изменений.
- «Альфа и проверки» содержит порядок проверки и известные ограничения.
- Детальные исходные значения оружия и способностей находятся в assets/balance. Если число в документе разошлось с кодом, сначала проверь источник и актуальный запрос пользователя; затем обнови обе стороны.

## Запуск

Открыть project.godot в Godot 4.7.2 и запустить основную сцену scenes/main.tscn. На этой машине редактор находится в /Applications/Godot.app/Contents/MacOS/Godot. Desktop использует Forward+, мобильный профиль — Compatibility.

Если сохранений нет, появляется «Выбери мир»: три карточки независимых сохранений. Только явное нажатие «Создать мир» создаёт файл. С выбранным существующим профилем игра входит в хаб. «Миры» в карточках сохранения и три региона кампании — разные сущности: один профиль может проходить всю кампанию.

## Справочники внутри игры

Пауза / планшет → Энциклопедия: игровой справочник из data/encyclopedia.json.

Пауза / планшет → Тех. информация: эти документы. Левая колонка показывает папки и документы; «Обновить» перечитывает дерево и выбранный файл с диска. Никакой второй вручную поддерживаемой копии не требуется.

В редакторе источник — res://guides. В экспортированной игре внутри пакета лежит снимок этой папки на момент сборки. Для обновления без пересборки можно положить полную папку guides в каталог пользовательских данных игры: user://guides. Если она существует, просмотрщик читает её вместо встроенной. Для возврата к встроенным документам нужно убрать внешнюю папку и нажать «Обновить».

На macOS каталог пользовательских данных этого проекта обычно находится в ~/Library/Application Support/Godot/app_userdata/Рубеж - 13/. Не удалять его ради проверки или починки запуска.
