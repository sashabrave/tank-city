# Минилеса «Рубеж — 13»
Оригинальные низкополигональные модели, созданные в Blender 5.2.2 через Blender MCP для этой задачи. Внешние модели и текстуры не использованы.

vegetation_tiles.blend — редактируемая сцена с 15 клетками. build_tiles.py — воспроизводимая сборка. Пять семейств по пять вариантов (tools/build_vegetation_v6.py, VARIANTS); корни на z=0, максимальная ширина клетки 0,94. В GLB координаты преобразованы в Y-up; каждый файл содержит только одну клетку у начала координат. Источник исключён из игрового экспорта вместе с assets/source.

WindData экспортируется как COLOR_0: гибкость, фаза, частота дерева. vegetation_wind.gdshader использует эти данные только для движения, цвет задаётся отдельно. Корни и камни закреплены. Бюджет движений меньше 0,04 клетки. При повторном экспорте обязательно export_vertex_color='ACTIVE', use_selection=True, use_active_scene=True; имя файла берётся из tile_id, чтобы Blender-суффиксы .001 не создавали дубли.
