# GPT Image 2.5 — альтернативный комплект

Все 17 генераций выполнены в Higgsfield с model `gpt_image_2_5`, variant flare, quality high, resolution 2k. Ответы сервиса подтверждают ту же модель; встроенный image_gen не использовался. `generation.json` сохраняет точные промпты, reference media IDs, job IDs и результаты.

Визуальные входы: прежний cat-atlas-reference.jpg, support-sheet.png и workshops-reference.jpg из родительской папки (созданы до Nano Banana), а также реальные игровые dog-game-reference.jpg и mortar-game-reference.jpg. Коррекции 20/21 ссылаются только на новые GPT-результаты. Никакое Nano Banana изображение не использовано в генерации.

Принятые листы: 20 — портреты;21 — миниатюры;2 — враги;3 — мастерские;10–19 — группы 82 иконок, с заменой abilities/field_repair отдельным листом 22. Листы 0/4 — промежуточные версии до исправления пулемёта/гранатомёта. Они не используются игровым комплектом.

Нарезка: удалена низкоальфовая дымка; целые связные силуэты распределены по ячейкам без обрезания соседними границами. PNG имеют прозрачные поля; конечные иконки 512×512. Атласы сохранены в прежних размерах и порядке. Финальные файлы — `assets/illustrations/gpt_image_2_5/`.

Проверены 86 пар файлов: одинаковые размеры/пути,82 разных хеша иконок в каждом комплекте. Оконный Godot в отдельном проекте без игровых autoloads и сохранений отрисовал 82 GPT-иконки на тёмном/светлом фоне, оба котоатласа и 16 врагов в 32/48/64 px. Кадры `godot-*.png`, отчёт `validation.json`. Это просмотр ассетов; сам переключатель ещё должен реализовать Клод.

Превью: `icons-dark.png`, `icons-light.png`, `miniatures-preview.png`. Надписи на сводных превью технические; на самих PNG текста нет.
