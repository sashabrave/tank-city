# Enemy atlas v1
Generated with built-in image_gen, transparent PNG, 4×4 equal cells. Runtime regions are selected in scripts/ui/enemy_type_icon.gd. Status badges are drawn separately; no separate status textures.

Prompt:
Create one production PNG sprite atlas for a military game UI. Exactly 4 columns by 4 rows, equal square cells on transparent background, 16 separate centered icons, generous padding in each cell. No text, labels, grid, badges or background. Minimal chunky ivory/cream military silhouettes with thick dark olive outlines and only a few olive interior marks. Consistent three-quarter view, readable at 32 pixels. Each icon fills 75% of its cell. Strict row-major order: row1 helmet infantry with pistol, helmet infantry with shotgun, helmet infantry with compact SMG, helmet infantry with assault rifle. Row2 infantry holding large riot shield, infantry with grenade launcher, sniper with conspicuously long scoped rifle, infantry carrying shoulder RPG with pointed rocket. Row3 dune buggy with roll cage, stationary grenade mortar turret on tripod, armored personnel carrier with wheels, tracked tank. Row4 heavy commander tank with double barrels, quadcopter drone with four rotors, small bomb-carrying ground drone, military commander helmet with single star. Flat clean hand-designed game pictograms, bright warm off-white fill, bold distinct silhouettes, no realistic textures or fine details. All 16 icons must remain entirely inside their own equal cell.
