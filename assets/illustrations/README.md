# Альтернативные иллюстрации

Два совместимых набора по 86 PNG. Структура подкаталогов одинакова; `manifest.json` связывает исходный путь с обоими вариантами и фиксирует размер/хеш.

- `gpt_image_2_5/` — новая генерация GPT Image 2.5 через Higgsfield. Референсы только прежние, до Nano Banana, плюс реальные игровые модели. 82 уникальные иконки и 4 атласа.
- `nano_banana/` — отдельная неизменённая копия ранее подготовленного комплекта. Скопирована для переключателя, не использована как визуальный референс новой генерации.

Принятые общие ассеты (оружие/предметы/эффекты, сердца, гайд, логотип, служебные SVG) не дублируются. Исходные игровые пути оставлены на месте. Код переключателя здесь не реализован.

Инструкция Клоду: `docs/history/guides/07_illustration_variants.md (переключатель убран в 0.7.0, остался один набор GPT)`. GPT-исходники и проверка: `assets/source/cozy_ui_2026/gpt_image_2_5/`.
