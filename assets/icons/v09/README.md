# Tank City — unified low-poly icons

Generated with the built-in image_gen tool in four sheets, sliced to 512×512 transparent PNG. Olive, ivory, graphite and orange; faceted military miniature style.

Generation prompts, full sheets, preview and replacement manifest: `output/icons-unified/`. Previous icons and consuming scripts: `.asset-library-backups/icons-before-unified-20260927-003042`.

Stable filenames retain game IDs. v09 migrated from SVG to PNG; UiKit, LootCatalog and CombatSystem updated. World sprite size is independent of texture resolution.
