# Tank City: редактирование без знакомства с кодом

## Первый запуск Godot

1. Открой Godot → **Import**, выбери `project.godot` из папки проекта → **Import & Edit**.
2. Слева снизу **FileSystem** — файлы. Двойной щелчок по `.tscn` открывает сцену.
3. Слева сверху **Scene** — элементы открытой сцены. Выбери элемент, справа появится **Inspector** с его свойствами.
4. **F5** запускает всю игру, **F8** останавливает. На Mac может понадобиться Fn. То же можно сделать кнопками ▶ и ■ сверху справа.
5. Сохраняй изменения перед запуском: **Scene → Save All Scenes**. У отдельно открытого ресурса `.tres` используй кнопку сохранения ресурса в Inspector. После изменения баланса останови игру и запусти снова.

Игровой прогресс хранится отдельно. Изменение исходных параметров не сбрасывает открытые рецепты или купленные уровни: итоговые статы персонажа складываются с ними. Не нажимай «Обнулить профиль», если хочешь сохранить прогресс.

## Баланс в Inspector

Открой `scenes/editor/balance_workbench.tscn`, выбери **BalanceWorkbench**. Справа раскрой **Balance**. Это общие ресурсы, которые использует настоящая игра, а не тестовая копия.

Можно также открыть нужный `.tres` прямо из FileSystem:

| Хочу поменять | Файл / раздел | Главные параметры |
| --- | --- | --- |
| Урон пистолета, дробь, темп огня | `assets/balance/weapons/pistol.tres` и другие оружия | Damage — урон одной пули; Interval — секунд между выстрелами; Speed — скорость пули; Range — дальность; Pellets — число пуль |
| Способность | `assets/balance/abilities/*.tres` | Cooldown — пауза между применениями; Power — урон/HP/длительность (зависит от способности); Price — цена открытия |
| Прочность и скорость врага/техники | `assets/balance/enemies/*.tres` | Health, Move Speed; Enemy Damage/Enemy Interval — вражеская атака; Damage/Fire Interval — базовые параметры союзной техники; Player Speed — скорость занятой машины |
| HP героя и базы | `assets/balance/combat.tres` | Hero/Base Health; здесь же запал/радиус гранаты и задержки волн |
| Миры: здоровье, урон, боссы | `assets/balance/campaign.tres` | World Health / World Damage / World Boss Health — по одному значению на мир; Health Step Per Field (мир 1 и остальные), Damage Step Per Field |
| Сколько врагов в волне | тот же `campaign.tres` | Wave Base Size + Wave Size Per Field × поле + Wave Size Per Wave × волна + Wave Size Per Star × звёзды; Vehicle Wave Minimum; в бесконечном режиме Endless Size Per Sector / Cap |
| Сколько врагов одновременно | тот же `campaign.tres` | Active Base + номер мира + поле / Active Fields Per Step, не больше Active Cap |
| Случайные дроны | тот же `campaign.tres` | First Surprise Min/Max — первый выезд; Surprise Delay Min/Max — следующие; Surprise Active Cap |
| Цены, дроп, лечение | `assets/balance/economy.tres` | Upgrade Base/Step Cost; Building Costs; Heart/Bonus Chance; Heal Amount; Chest Alloy |
| Цена второго навыка | тот же `economy.tres` | Second Ability Slot Documents, сейчас 12 секретных документов; победа над гигабоссом всё равно обязательна |

**Пример:** пистолет стреляет раз в 0,60 с. Установи Interval = 0,50, сохрани ресурс, перезапусти игру — получится 2 выстрела в секунду. Speed = 16 меняет скорость полёта пули, а не частоту стрельбы.

**Состав волны.** Размер считается формулой из `campaign.tres`, а виды врагов — по ступени поля: поля 1–2 только пехота, 3–4 добавляют лёгкую технику, 5–6 тяжёлую. Wave Cost в ресурсе врага влияет только на порядок подкреплений командира. Профессионализм врагов (задержка прицела, паузы, окопы, штурм) — `scripts/combat/professionalism.gd`.

Новый мир добавляется одной записью в каждый массив World ... и строкой в `Campaign.WORLDS` (название, размеры полей).

Настройки способности Description/Role — текст подсказки. Если меняешь число, указанное в описании, обнови и описание. Ресурсы задают базовые значения; временные карточки и постоянные улучшения применяются поверх них.

## Настоящие сцены интерфейса

Открой сцену и переключись сверху на **2D**. Выбери узел слева, передвинь мышью; **Inspector → Layout → Transform** задаёт положение и размер точнее. **Theme Overrides → Font Sizes** — размер текста, **Colors** — цвет, **Styles** — фон и скругление панели/кнопки.

| Что редактировать | Сцена |
| --- | --- |
| Бой: HP, оружие, список волн, кнопки, панель навыков | `scenes/ui/battle_hud.tscn` |
| Расположение трёх наград, заголовков и переброса | `scenes/ui/rewards_screen.tscn` |
| Военный сундук | `scenes/ui/chest_screen.tscn` |
| Механик / генерал: выбор улучшения | `scenes/ui/service_rewards.tscn` |
| Содержимое карточек наград | `choice_upgrade.tscn`, `choice_chest.tscn`, `choice_service.tscn` в той же папке |
| Пауза и рюкзак | `pause_screen.tscn`, `inventory_slot.tscn` |
| Основной экран хаба | `hub_screen.tscn` |
| Рамка мастерской, вкладки, закрытие | `character_workshop.tscn`, `weapon_workshop.tscn`, `bonus_workshop.tscn` |
| Строка улучшения персонажа | `upgrade_row.tscn` |
| Карточки в магазинах | `weapon_card.tscn`, `bonus_card.tscn`, `ability_card.tscn` |

Все эти шаблоны действительно используются игрой. Изменение внутреннего расположения и оформления карточки применяется ко всем её экземплярам. Список карточек и расстояние между рядами в некоторых мастерских пока формируются кодом; форма самой карточки — в сцене.

### Три частых примера

**Переместить здоровье.** В `battle_hud.tscn` выбери **HealthPanel** и передвинь. Под ним **WeaponPanel**. Игра обновляет значения HP, но не перезаписывает твоё положение панелей.

**Сделать название оружия крупнее.** **WeaponPanel → WeaponName → Theme Overrides → Font Sizes → Font Size**. Проверь длинное название, чтобы оно помещалось. Сам текст названия берётся из ресурса оружия.

**Изменить наградную карточку.** В `choice_upgrade.tscn` выбери **Title**, **Description**, **Icon**, **ChooseButton**. Передвинь нужное или поменяй шрифт. Чтобы переместить карточки целиком, открой `rewards_screen.tscn` и двигай **Panel → Card1/2/3**.

Тексты HP, цен, названий и эффектов в сцене — примеры для предпросмотра. Во время игры они заменяются текущими данными; редактировать содержание нужно в соответствующих ресурсах. Цвет фона карточки меняется с редкостью, а её скругление/рамка берутся из сцены.

**Не переименовывай и не удаляй служебные узлы** вроде HealthPanel, Title, ChooseButton: код находит их по имени. Менять позицию, размер, шрифт, иконки-превью и стили можно. Для отдельной панели стиля выбери **Make Unique**, если не хочешь менять все элементы, разделяющие этот стиль.

Anchors удерживают панели у края экрана при изменении размера окна. У Skills и Inventory используется контейнер: дочерние элементы размещаются автоматически. У них меняй Minimum Size и Separation контейнера, а не перетаскивай каждый элемент отдельно.

## Что пока остаётся в коде

Карта маршрута (включая 3D-миниатюры), экран настроек, строительство, капсула классов, подробная статистика, финальные экраны и отдельные динамические вкладки ещё создаются программно. Их текущие файлы: `route_map.gd`, `settings.gd`, `hub.gd`, `hud.gd`. Основная игровая сцена и поле также генерируются; не ожидай увидеть готовую комнату, открыв пустой корень Arena.

## Безопасный рабочий цикл

Поменяй один параметр → сохрани → F5 → проверь → F8. Для второй зоны и гигабосса используй уже имеющиеся тестовые переходы на карте и повтор прокачки. Перед большим редактированием скопируй папку проекта. Старые резервные копии в `tmp` не являются рабочими файлами игры.

## Полигон объектов

В хабе появилась кнопка «ПОЛИГОН · Объекты». Крупный план, все стволы, неподвижные цели и возрождение через 2 секунды. Подробности — `docs/TEST_GALLERY.md`. Интерфейс редактируется в `scenes/ui/gallery_screen.tscn`.
