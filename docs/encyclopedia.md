# Энциклопедия и общие тексты

В игре: планшет → Энциклопедия → **Edit dev** → **Редактировать**.

У обычной статьи доступны заголовок, раздел, подраздел, текст и путь к изображению. У связанного термина дополнительно редактируются название для всей игры и короткое описание. Кнопка «Сохранить и применить» обновляет текущую игру и `data/encyclopedia.json`. Предыдущая версия сохраняется в `.bak`; «Отмена» ничего не записывает. Ошибка записи показывается в редакторе, текущие тексты при этом не заменяются.

Редактирование включено при запуске из исходного проекта движком Godot (feature `editor`) либо с feature `dev`. В обычной экспортированной игре редактора нет. Изменённый JSON включается в следующую сборку. Это локальный инструмент автора, не система серверных ролей.

## Что связано

Общие названия: напор, броня, сплав, документы, песок, вода, лёд и основные враги. Названия заменяются в игровых Label/Button/Label3D/RichTextLabel и полосках характеристик, с учётом регистра и границ слов. Формы склонения автоматически не выдумываются; связный текст статьи редактируется отдельно.

Короткое описание напора подключено к карточкам усилений и стабилизатора через `{{pressure.description}}`. Общие короткие описания также выводятся в статье и подсказках к совпадающим названиям. Произвольный текст статьи не подменяет другие описания. Сохранение меняет единый файл данных, не переписывает GDScript и сцены.

## Формат файла

`terms` — словарь стабильных ID: `source` (исходное название, не менять), `name`, `description`.
`articles` — список статей: `id`, `category`, `section`, `title`, `text`, `image`, `term`.
Пустой `image` оставляет прямоугольную заглушку; путь вида `res://assets/...png` показывает картинку. Пустой `term` означает независимую статью. Подразделы и дополнительные разделы формируются из данных автоматически.

Правка через редактор применяется сразу. При ручной правке JSON перезапустите игру. Поиск охватывает названия, текст, разделы и связанные общие термины; игнорирует регистр и е/ё. Несколько слов ищутся одновременно.

Версия и билд экрана «Об игре» берутся из `application/config/version` и `application/config/build` в project.godot. Настройки: Видео, Звук, Управление, Интерфейс; сбрасывается только выбранная вкладка. Все статьи — рабочая редакция по текущей реализации, которую можно уточнять без изменения кода.

## Дерево и создание материалов

Слева от статей теперь два уровня: заголовок категории с раскрывающей стрелкой и подразделы с подсветкой выбора. Поиск работает внутри выбранного раздела; «Все» снимает фильтр. Основное меню планшета сворачивается стрелкой вверху до полоски SVG-иконок с подсказками.

В Edit dev: «+ Категория» снизу дерева, «+ Подраздел» внутри раскрытой категории, «+ Статья» над статьями. Переименование — двойной клик по названию, затем OK или Enter. Пользовательские категории и подразделы отмечаются `builtin: false` в `categories`; только их можно удалить. Удаление требует подтверждения и переносит статьи в «Без подраздела», сохраняя их содержимое. Пустые категории сохраняются в файле независимо от статей. Системные категории можно переименовать, но нельзя удалить.

Интерфейсные иконки извлечены из предоставленного Straight.svg (Uicons Straight Corners): меню, стрелки, книга, настройки, поиск, редактирование, корзина и музыкальные кнопки. Предметы и способности используют прежние игровые изображения.
