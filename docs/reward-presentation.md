# Оформление наград

Единая палитра: `LootCatalog.RARITY_COLORS` и `RARITY_NAMES`.

- 0 — Обычное: серебристый `#cbd5df`.
- 1 — Редкое: голубой `#55baff`.
- 2 — Эпическое: фиолетовый `#bc82ff`.
- 3 — Секретное: золотой `#ffd166` (включая особые чертежи).

Отдельного легендарного уровня сейчас нет. Цвета одинаковы у маркера, силуэта категории, подписи, рамки и оттенка фона. Объект и редкость — две строки; предметная иконка сохраняет оригинальную графику в цветной рамке. SVG-силуэты окрашиваются при отрисовке.

Карточки появляются через 90/190/290 мс, затем с 600 мс выезжают кнопки. Выбор заблокирован до конца анимации; закрытие окна сбрасывает блокировку.

Звук выбирается по максимальной редкости набора. Для каждого уровня — три синтезированных WAV-варианта мягкого мажорного перелива, без повторения предыдущего. Высшие уровни добавляют ноты и тихий аккорд. Длительность 0,55–0,94 с, общий уровень −23 dB, стандартный канал эффектов и настройка звука.

Проверки: `tests/reward_presentation.tscn`, `tests/reward_reveal.tscn`.
