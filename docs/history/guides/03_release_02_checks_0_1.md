# Проверки альфы 28 сентября 2026

Godot 4.7.2, macOS, Apple M4. Для визуальных проверок использован Forward+ / Metal; для аудио — CoreAudio. Пользовательские профили не сбрасывались; тесты записи использовали временные каталоги.

## Пройденные сценарии
- Создание нового профиля, три слота, удаление последнего и повторный вход без сохранений.
- Валидация профиля и резервное восстановление; ожидаемая ошибка записи в недоступный тестовый путь обработана.
- Диалоги прибытия, независимый кулдаун дронов и стабильное отображение текста.
- Генерация укрытий трёх миров, варианты боссов, пороги щитов гигабосса и охрана генераторов.
- Переключение языка, темы и освещения.
- Чтение папки guides и повторное сканирование документов.
- Память планшета при переходе между вкладками и повторном открытии.
- Бесконечный старт без карты, три сервиса, возвращение в бой, новый цикл и восстановление перед сервисным выбором.
- Музыка пяти контекстов, пауза/возобновление радио, продолжение музыки при паузе игры и ненулевой выходной аудиосигнал.
- Автоматический поиск непереведённых исходных надписей и форматных шаблонов: пропусков не найдено. Это не заменяет ручную редактуру всего английского текста.

## Артефакты
Снимки экранов находятся в screenshots: arrival-ru, arrival-en, boss-heavy, boss-twins, boss-medium, gigaboss-generator, profiles-first-launch, technical-guides, endless-services.

macOS-архив готовится в build/macos/TankCity-alpha-0.1.0.zip. Внутри должны присутствовать документы guides, английский TSV и аудиокаталоги. Локальная подпись не является нотарификацией для распространения.

## Не проверено полностью
Длительное прохождение поздних бесконечных циклов, полный баланс классов и прокачки, производительность слабых устройств, iOS-сборка и управление на физическом мобильном устройстве. Эти пункты остаются следующими задачами, а не результатами текущих автоматических проверок.
