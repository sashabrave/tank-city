# Задание GPT: графика для 0.7

Это задание можно целиком передать ChatGPT, у которого есть доступ к репозиторию. Он сам рисует листы, нарезает их, кладёт файлы по путям ниже и заменяет старые. Код уже ждёт эти файлы: если файла нет, игра показывает запасной вариант. Поэтому файлы можно класть по одному, ничего не сломав.

## Общие правила

- Стиль — как у текущего набора GPT (`assets/illustrations/gpt_image_2_5`): мягкий объёмный «игрушечный» 3D, крупные формы, военная тема с котами, тёплый свет сверху‑слева, без контурных обводок.
- PNG с прозрачным фоном. Без плашек, рамок, подложек, теней-прямоугольников и текста.
- **Всё, у чего есть направление (оружие, техника, стрелки, пули, взгляд персонажа), смотрит вправо.** Дуло, нос машины, остриё — к правому краю. Ничего не смотрит влево или из кадра.
- Предмет занимает кадр почти целиком: около 6% прозрачного поля с каждой стороны. Интерфейс сам обрезает прозрачные поля и растягивает картинку на всю ячейку.
- Рисуй листом (сеткой), потом нарежь на отдельные файлы точно с именами из таблиц. Имена и пути менять нельзя.
- После замены открой проект в Godot (или запусти `Godot --headless --path . --editor --quit`), чтобы появились файлы `.import`.
